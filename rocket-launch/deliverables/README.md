# Rocket Group video delivery

- `rocket-group-launch.mp4`: exactly 15.000 seconds, 1920 × 1080, 60 fps; H.264 video with stereo AAC audio.
- `rocket-group-editable.zip`: complete editable HTML/CSS/JavaScript project, original logo assets, fonts, music and SFX stems, and opening/rendering instructions. Extract the ZIP and read `rocket-launch/README.md`.
- `thumbnail.png`: final-frame cover image.

On GitHub, open a file and use **Download raw file**. If the repository is private, sign in with an account that has access.

The live website was inaccessible from the production environment (proxy CONNECT 403), so the film uses the user-approved original-logo introduction. The named motion-system and higgsfield-saas skills were unavailable; production used HyperFrames and GSAP. No website interface, service claim, or unverified business messaging was fabricated.
