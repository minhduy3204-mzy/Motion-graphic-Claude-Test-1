## Choreography rules for the new fifteen-second film

1. **One persistent document.** Keep the same application name, document name, sidebar tree, toolbar, canvas, rulers, inspector, and artwork throughout. Camera reframing can crop the workspace, but it must preserve the underlying coordinate system.
2. **One clear object story.** Begin with a deliberately unfinished composition, select one headline or hero object, change a meaningful property, then reveal the improved result. Avoid changing several unrelated controls too quickly to understand.
3. **Selection has a single source of truth.** The selected canvas object, sidebar row, inspector title, property values, and bounding box must derive from the same object ID. The displayed font size, position, and active color must match the actual rendered state.
4. **Every action has an observable result.** Cursor arrival precedes press, press causes focus/selection, control adjustment changes the appropriate property, and release settles the result. Align sound cues to press frames rather than cursor travel starts.
5. **Carry geometry through transitions.** Keep the selected headline and selection frame continuously visible while the camera tracks from canvas to property panel and back. An expanding artboard or selection edge can become the final presentation surface.
6. **Use shallow camera depth.** Interface chrome is one stable plane; artwork, cursor, handles, and inspector accents can sit slightly above it. Perspective must be mild during reading and stronger only while travelling between targets.
7. **Keep momentum coherent.** Favor one lateral movement direction, overlap camera motion with property interpolation, and let major type rest after it resolves. Avoid hard stops between UI action and result.
8. **Use typography as the main visual payoff.** A selected title can change weight, size, or tracking, then snap into a better composition. Text must auto-fit to the named object's editable bounds rather than cover controls.
9. **Conclude with a stable brand state.** Finish the hero reveal by approximately 12.5 seconds and hold the invented app name plus a concise CTA through 15.0 seconds. Maintain a visible relationship to the same workspace document as the interface recedes.
10. **Retime events rather than independent clips.** Scene durations set action times, camera waypoints, property interpolation, and click/accent/whoosh positions through one shared timeline. Test at least one altered duration for continuity and sound sync.

## Suggested continuous sequence

- **0.0–2.4 s — Find the object:** full workspace establishes the document. Cursor selects the hero title; the sidebar row, bounding box, and inspector update together.
- **2.4–5.8 s — Refine the design:** a camera track follows the cursor to a meaningful type/color control. A precise press and short adjustment alter only the selected object, with readable before/after states.
- **5.8–9.2 s — See the response:** camera travels back with the changing headline as spacing and supporting composition settle. Rulers and alignment guides confirm the layout without becoming decoration.
- **9.2–12.5 s — Present the composition:** a motivated artboard expansion or preview-button action produces a refined presentation view of the same document. Keep identity, copy, colors, and object positions continuous.
- **12.5–15.0 s — Name and act:** the canvas becomes a clean brand lockup with invented app identity and an explicit CTA. Let the soundtrack resolve while the image holds.
