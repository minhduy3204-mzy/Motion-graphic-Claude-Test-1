Rocket Studio is the invented app identity requested for this film. The canvas is a website concept for Rocket Group. Reference footage and audio are excluded.

HyperFrames and Remotion were both used. Higgsfield tools and motion skills were unavailable in this session; no Higgsfield-generated content is included. All graphics are original editable code.

Checks: exact duration and frame count, full decode, normal-speed playback, all cursor targets, consistent UI values, long-copy fitting, scene/audio retiming, clean contrast/layout, final hold, and source lint/type checks. Download checksums are in `checksums.json`.
